# agent-skills

A collection of [Agent Skills](https://agentskills.io) by Kazuki Nagata.

## Skills

| Skill | Description |
| --- | --- |
| [subtract](skills/subtract/SKILL.md) | Cut a text down to what matters, and list what was cut. |

## Install

With [skills](https://github.com/vercel-labs/skills):

```sh
npx skills add kazukinagata/agent-skills --skill subtract
```

With [GitHub CLI](https://cli.github.com/manual/gh_skill_install) (v2.90.0+):

```sh
gh skill install kazukinagata/agent-skills subtract
```

Add `-g` (npx skills) or `--scope user` (gh skill) to install for your user instead of the current project.
